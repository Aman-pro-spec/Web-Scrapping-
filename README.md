## 📝 About The Project

Collecting customer feedback manually for market research is tedious. This project automates the extraction of **customer reviews, ratings, and comments** directly from Flipkart product pages.

This tool is designed to help Data Analysts and Developers gather real-world datasets for Sentiment Analysis, NLP projects, or Product Research.

### ✨ Key Features

* **🔍 Automated Extraction:** Scrapes product names, ratings, review titles, and full comments.
* **📄 CSV Export:** Automatically saves the scraped data into a structured `.csv` file for easy analysis.
* **🔄 Pagination Handling:** Navigate through multiple pages of reviews to gather a complete dataset.
* **⚡ Efficient Processing:** Built with lightweight libraries for fast execution.

## 🚀 Getting Started

Follow these steps to use the scraper on your local machine.

### Prerequisites

* Python 3.x installed

### Installation

1.  **Clone the repository**
    ```bash
    git clone [https://github.com/Aman-pro-spec/Web-Scrapping-Using-Python.git](https://github.com/Aman-pro-spec/Web-Scrapping-Using-Python.git)
    cd Web-Scrapping-Using-Python
    ```

2.  **Install dependencies**
    ```bash
    pip install requests bs4 pandas
    ```

3.  **Run the Script**
    ```bash
    python scraper.py
    ```
    *(Note: Replace `scraper.py` with your actual main python file name)*
